# Генератор цитат/фактов с выбором тематики

Приложение на Python с графическим интерфейсом (tkinter) и веб-версией (FastAPI),
которое выдаёт случайные цитаты или интересные факты по выбранной теме. Данные
хранятся в PostgreSQL, развёрнутой в Docker. Лабораторная работа №3, вариант №10.

## Возможности

- Выбор темы из выпадающего списка (Мотивация, Наука, История, IT, Философия, Факты о животных).
- Генерация случайной цитаты/факта по выбранной теме.
- История сгенерированных цитат (таблица в окне + в БД).
- График активности: сколько раз сгенерировали по каждой теме (matplotlib).
- Журнал действий (лог) в окне приложения с временными метками.
- Избранное: сохранение понравившихся цитат в БД, отдельное окно для просмотра и удаления.
- Меню: Файл, Правка, Справка. Пункт «Выход» в меню и кнопкой.
- Обработка ошибок через собственные исключения (GeneratorError, ThemeNotFoundError,
  EmptyThemeError, DatabaseError, FavoriteError).
- Веб-версия на FastAPI: страница в браузере с генерацией цитаты и историей.
- Развёртывание PostgreSQL + FastAPI в Docker через docker-compose.

## Стек

- Python 3.10+
- tkinter (GUI)
- matplotlib (график)
- psycopg2 (драйвер PostgreSQL)
- PostgreSQL 16 (база данных)
- FastAPI + uvicorn (веб-версия)
- pytest (тесты)
- Docker / Docker Compose (контейнеризация)

## Архитектура

Приложение построено по слоистой архитектуре:

```
   main.py
      ↓
   ui/main_window.py  (GUI, tkinter)
      ↓
   services/quote_generator.py  (бизнес-логика)
      ↓
   storage/*  (репозиторий + сервисы избранного/истории)
      ↓
   PostgreSQL  (таблицы: themes, quotes, favorites, history)
```

Верхний слой знает про нижний, но не наоборот. `QuoteGenerator` не знает про tkinter и
не лезет в SQL напрямую — он вызывает методы репозитория. Это позволяет тестировать
логику без GUI и без БД, подменяя репозиторий фейком.

## Установка и запуск (локально, tkinter-версия)

1. Установить PostgreSQL 16+ и запомнить пароль пользователя `postgres`.
2. В DBeaver (или psql) создать базу:
   ```sql
   CREATE DATABASE quote_generator;
   ```
3. Подключиться к новой базе и выполнить скрипт из файла `init.sql` (создаст таблицы
   и зальёт 6 тем + 120 цитат).
4. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. В файле `ui/main_window.py` указать свой пароль в переменной `DSN`:
   ```python
   DSN = "dbname=quote_generator user=postgres password=ТВОЙ_ПАРОЛЬ host=localhost port=5432"
   ```
6. Запустить приложение:
   ```bash
   python main.py
   ```

## Запуск веб-версии локально

1. Выполнить шаги 1–4 из раздела выше (PostgreSQL + данные + зависимости).
2. Запустить FastAPI:
   ```bash
   uvicorn web.app:app --reload --host 0.0.0.0 --port 8000
   ```
3. Открыть в браузере: `http://localhost:8000`

## Запуск в Docker (веб-версия + PostgreSQL)

Требуется Docker и Docker Compose.

1. Собрать и поднять:
   ```bash
   docker-compose up --build
   ```
2. Подождать, пока БД инициализируется (15–30 секунд при первом запуске — выполнится `init.sql`).
3. Открыть в браузере: `http://localhost:8000`
4. Остановить: `Ctrl+C` в терминале, где запущен `docker-compose`.
5. Удалить контейнеры и данные: `docker-compose down -v`.

Контейнеры:

- `db` — PostgreSQL 16, порт 5433 снаружи (чтобы не конфликтовать с локальной БД),
  5432 внутри. Инициализационный SQL-скрипт `init.sql` выполняется автоматически при
  первом старте и создаёт таблицы + 120 цитат.
- `web` — FastAPI, порт 8000. Подключается к БД через `host=db`.

## Запуск тестов

```bash
pytest
```

Тесты проверяют логику `QuoteGenerator` и валидацию модели `Quote`. GUI и БД в тестах
не задействуются — репозиторий подменяется фейком `FakeRepository`, что позволяет
тестировать генерацию без подключения к PostgreSQL.

## Краткая справка

| Элемент | Назначение |
|---|---|
| Combobox «Тема» | выбор одной из 6 тем |
| Кнопка «Сгенерировать» | получить случайную цитату/факт по теме |
| Поле «Цитата» | вывод текущей сгенерированной цитаты |
| Кнопка «Скопировать» | копировать текущую цитату в буфер обмена |
| Кнопка «Добавить в избранное» | сохранить цитату в БД (таблица favorites) |
| Кнопка «Показать избранное» | открыть окно со списком избранных цитат |
| Кнопка «Очистить историю» | очистить таблицу history |
| Таблица «История» | последние 50 сгенерированных цитат |
| График активности | сколько раз сгенерировали по каждой теме (matplotlib) |
| Поле «Лог» | журнал действий пользователя с временными метками |
| Меню «Файл» | Показать избранное, Выход |
| Меню «Правка» | Очистить историю |
| Меню «Справка» | О программе |
| Веб-версия `/` | HTML-страница в браузере с генерацией и историей |
| `GET /api/themes` | список тем (JSON) |
| `GET /api/quote?theme=...` | сгенерировать цитату (JSON) |
| `GET /api/history` | история генераций (JSON) |
